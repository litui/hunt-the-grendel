# Hunt the Grendel

This is a Claude-translated version of the original 1976 port of Hunt the Wumpus.

## Claude's translation key

Here's a translation key for the non-obvious decisions made:

**Vocabulary choices (all verified against Bosworth-Toller or etymological record):**

| Original | Old English | Notes |
|---|---|---|
| INSTRUCTIONS | LAROWDOMAS | *lār* (teaching) + *dōmas* (judgements/rulings) — attested compound |
| HUNT THE WUMPUS | HUNT THE GRENDEL | Grendel is already OE nominative |
| YOU LOSE | ÞU UNDERLIGEST | *underlicgan* — "to lie under, be defeated" — Battle of Maldon register |
| YOU WIN | ÞU SIGAST | *sigan* — "to be victorious" |
| ROOM | COFA | attested OE: inner chamber, cell |
| TUNNEL | ÞYREL | "hole, perforation, passage" — attested |
| PIT | PYTT | direct OE cognate, attested in Bosworth-Toller |
| BAT (animal) | HRĒREMŪS | the actual OE word for bat — "rattle-mouse" |
| ARROW | FLAN | the poetic OE word; also in Beowulf (*flānbogan* = bowman) |
| SHOOT | SCEOTAN | OE strong verb, directly attested in Beowulf |
| MOVE/GO | FARAN / GANGAN | both attested; *faran* used for "travel", *gan* for "go" |
| I SMELL A WUMPUS | IC STINCE GRENDEL | *stincan* — to emit odour, attested |
| I FEEL A DRAFT | IC FELE LYFTDRÆFT | *lyft* (air) + *dræft* (draught/current) |
| BATS NEARBY | HRĒREMȲS NĒAH | plural of hrēremūs + *nēah* (near) |
| MISSED | OFSCOTEN | past participle of *ofsceotan* — "shot past/missed" |
| WHERE TO | HWIDER | "whither" — direct OE survival |
| SAME SET-UP | ILCE GEARWUNGE | *ilca* (same) + *gearwung* (preparation, arrangement) |
| WELCOME | WES ÞU HAL | the canonical OE greeting — "be thou whole" |

The Y/N prompt switch is changed to G/N (*Gea* = yes, *Na* = no) and S/M to S/F (*Sceotan*/*Faran*) for internal consistency.

## Original Intro: original-hunt-the-wumpus
Original source code of text-based game [Hunt The Wumpus](https://en.m.wikipedia.org/wiki/Hunt_the_Wumpus) written in [BASIC](https://en.m.wikipedia.org/wiki/BASIC) by late  [Gregory Yob](https://en.m.wikipedia.org/wiki/Gregory_Yob) (1945–2005) in 1973. Claimed to be the earliest survival horror game.
This source code is originally published in [October 1975 issue of Creative Computing](https://archive.org/details/CreativeComputingv01n05SeptemberOctober1975/page/n55/mode/1up) and [The Best of Creative Computing](https://www.atariarchives.org/bcc1/showpage.php?page=250) in 1976, which fortunately can be found online pretty easily, so it didn't take too long to get this source code. 

I uploaded this for the purpose of not only making it easily accessible but also for the sake of preservation in case those links are taken down. You can run this on a BASIC interpreter or, as this code is in public domain, make changes to it as long as you're not doing it in this repository. Do whatever you want with it.

I provided the source code as is, no alterations or changes were ever made. I won't make any changes to it because I wanted to keep this code strictly original as possible. 

Enjoy.
